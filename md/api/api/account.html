    Restful API

    犀牛 11/5/2024

    基础 url: https://account.pannovel.com

    # 注册

    • 接口地址: /register
    • 请求方式: POST
    • 接口描述: 注册
    请求参数 类型 是否必须 描述
    name string 是 用户名，长度在 4 - 10
    password string 是 密码，长度在 4 - 20，明文传输
    language string 是 语言标识

    # 登录

    • 接口地址: /login
    • 请求方式: POST
    • 接口描述: 登录
    请求参数 类型 是否必须 描述
    name string 是 用户名
    password string 是 密码，明文传输
    language string 是 语言标识

    # 修改密码

    • 接口地址: /change_password
    • 请求方式: POST
    • 接口描述: 注册
    请求参数 类型 是否必须 描述
    name64 string 是 用户的唯一 id，64 位
    old_password string 是 密码，长度在 4 - 20，明文传输
    new_password string 是 密码，长度在 4 - 20，明文传输
    language string 是 语言标识

    # 获取书架

    • 接口地址: /bookshelf/get_bookshelf
    • 请求方式: POST
    • 接口描述: 获取书架
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    status int 是 书籍状态
    - 1: 正在看
    - 2: 已经看完
    page int 是 第几页
    limit int 是 每页有几个
    language string 是 语言标识

    除了常态的 book 属性外，另外增加两个新的属性

    • read_categories : 阅读到第几章
    • read_time : 上一次阅读时间

    # 获取书籍进度

    • 接口地址: /bookshelf/get_book_info
    • 请求方式: POST
    • 接口描述: 获取书籍进度
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    subbook64 string 是 书籍唯一 id，64位
    language string 是 语言标识

    如果用户曾经收藏过本书，则返回该书的进度，否则都会返回进度为 1

    # 收藏至书架

    • 接口地址: /bookshelf/add_bookshelf
    • 请求方式: POST
    • 接口描述: 获取书架
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    subbook64 string 是 书籍的 subbook64
    chapter int 是 正在阅读的章节数，第几章
    language string 是 语言标识

    # 从书架去除

    • 接口地址: /bookshelf/delete_bookshelf
    • 请求方式: DELETE
    • 接口描述: 获取书架
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    subbook64 string 是 书籍的 subbook64
    language string 是 语言标识

    # 是否在书架中

    • 接口地址: /bookshelf/is_in_bookshelf
    • 请求方式: POST
    • 接口描述: 是否在书架中
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    subbook64 string 是 书籍的 subbook64
    language string 是 语言标识

    返回布朗值。

    # 更新进度

    • 接口地址: /bookshelf/update_bookshelf
    • 请求方式: POST
    • 接口描述: 获取书架
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    subbook64 string 是 书籍的 subbook64
    chapter int 是 正在阅读的书籍章节
    language string 是 语言标识

    这个接口需要遵循以下特点

    • 当用户阅读的时候，每隔 5 秒调用该接口进行更新阅读章节
    • 只有主动收藏的书籍才能正确存储章节数，否则，将返回 022018

    # 修改书籍状态

    • 接口地址: /bookshelf/change_bookshelf
    • 请求方式: POST
    • 接口描述: 获取书架
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    subbook64 string 是 书籍的 subbook64
    status int 是 书籍状态
    - 1: 正在阅读
    - 2: 阅读完毕
    language string 是 语言标识

    # 获取评论

    • 接口地址: /comment/get_comments
    • 请求方式: POST
    • 接口描述: 获取评论
    请求参数 类型 是否必须 描述
    subbook64 string 是 书籍的 subbook64
    page int 是 第几页
    limit int 是 每页有几个评论
    language string 是 语言标识

    # 增加评论

    • 接口地址: /comment/add_comment
    • 请求方式: POST
    • 接口描述: 增加评论
    请求参数 类型 是否必须 描述
    name64 string 是 用户的 subbook64
    subbook64 string 是 书籍的 subbook64
    content string 是 评论
    language string 是 语言标识

    # 删除评论

    • 接口地址: /comment/delete_comment
    • 请求方式: DELETE
    • 接口描述: 删除评论
    请求参数 类型 是否必须 描述
    name64 string 是 用户的 subbook64
    subbook64 string 是 书籍的 subbook64
    comment_id string 是 评论id
    language string 是 语言标识

    # 获取用户设置

    • 接口地址: /setting/get_setting
    • 请求方式: POST
    • 接口描述: 获取用户设置
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    language string 是 语言标识

    # 修改设置

    • 接口地址: /setting/update_setting
    • 请求方式: POST
    • 接口描述: 更新用户设置
    请求参数 类型 是否必须 描述
    name64 string 是 用户唯一 id，64位
    country string 否 国家标识
    font_size int 否 字体大小
    line_spacing int 否 行间距
    display_status int 否 显示状态
    read_status int 否 阅读方式，默认是 1
    language string 是 语言标识
